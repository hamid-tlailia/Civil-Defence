# أسطول الدفاع المدني — قطر

تطبيق PWA تدريبي لأفراد الدفاع المدني الجدد: سبع سيارات، وكل خانة فيها، وكل معدة مع استعمالاتها وطريقة استعمالها ومخاطرها. عربي (افتراضي) وإنجليزي، يعمل بلا إنترنت بعد أول فتح.

## الرفع على GitHub Pages

1. أنشئ مستودعًا جديدًا (مثلًا `qcd-fleet`) واجعله **Public**.
2. ارفع كل ملفات هذا المجلد في **جذر** المستودع (وليس داخل مجلد فرعي).
3. `Settings` ← `Pages` ← في `Source` اختر `Deploy from a branch` ← الفرع `main` والمجلد `/ (root)` ← `Save`.
4. بعد دقيقة يصبح الرابط جاهزًا: `https://<اسم-حسابك>.github.io/qcd-fleet/`
5. افتح الرابط من الجوال ← قائمة المتصفح ← **إضافة إلى الشاشة الرئيسية**، فيعمل كتطبيق مستقل.

## الملفات

| الملف | الوظيفة |
|---|---|
| `index.html` | التطبيق كاملًا: الواجهة والبيانات والمنطق |
| `manifest.json` | بيانات التثبيت على الشاشة الرئيسية |
| `sw.js` | العمل بلا إنترنت |
| `logo.png` | الشعار الظاهر في الصفحة الرئيسية |
| `icon-192.png` · `icon-512.png` | أيقونة التطبيق بعد التثبيت |

## استبدال الشعار

`logo.png` الحالي شعار مؤقت. احفظ صورة شعار الإدارة العامة للدفاع المدني باسم `logo.png` بالضبط واستبدل الملف — يفضّل PNG مربّع بخلفية شفافة 512×512. ويُستحسن توليد `icon-192.png` و`icon-512.png` من الشعار نفسه بخلفية داكنة `#100D0B`.

## حساب المدير

الدخول من تبويب **حسابي** برقم `+974 7100 9494` فقط. الرمز يظهر حاليًا داخل الشاشة لأن المتصفح لا يستطيع إرسال رسائل SMS بنفسه. لتفعيل الإرسال الحقيقي: Cloudflare Worker يستدعي Twilio أو مزوّدًا محليًا، ثم يُستبدل عرض الرمز باستدعاء الـWorker.

المدير وحده يستطيع: التعديل على السيارات والخانات والمعدات، نشر الإشعارات، وتشغيل التدريب العشوائي.

## البيانات

تُحفظ محليًا في الجهاز. صدّر نسخة JSON من تبويب **حسابي** بعد كل جلسة إدخال، ويمكن استيرادها في أي جهاز آخر. لجعل البيانات مشتركة بين كل الأجهزة تلقائيًا يلزم ربط قاعدة بيانات على Cloudflare (D1 أو KV).

## ربط إرسال رمز التحقق بالبريد الإلكتروني (مجاني)

الدخول لحساب المدير صار بالبريد بدل رقم الجوال — بلا تكلفة ولا عقد مع مشغّل.

1. افتح `index.html` واضبط بريدك:
   ```js
   const ADMIN_EMAIL = 'your@email.com';
   ```
   ما دام فارغًا، أي بريد صحيح يُقبل مؤقتًا للتجربة.

2. لإرسال الرمز فعلًا للبريد: انشر `worker.js` على Cloudflare Workers مع مفتاح Resend المجاني.
   ```bash
   npm i -g wrangler
   wrangler login
   wrangler kv namespace create OTP     # انسخ الـ id إلى wrangler.toml
   wrangler secret put RESEND_KEY       # من resend.com — الخطة المجانية تكفي
   wrangler secret put ADMIN_PHONE      # ضع فيه بريد المدير
   wrangler deploy
   ```

3. في `index.html` استبدل توليد الرمز محليًا باستدعاء الـWorker:
   ```js
   await fetch(WORKER + '/send',   {method:'POST', headers:{'content-type':'application/json'},
     body: JSON.stringify({phone: email})});
   const r = await fetch(WORKER + '/verify', {method:'POST', headers:{'content-type':'application/json'},
     body: JSON.stringify({phone: email, code})}).then(x=>x.json());
   if (r.ok) { admin = true; await store.set('qcd_admin', {at:Date.now(), token:r.token}); }
   ```

الـWorker يدعم أيضًا الإرسال بالرسائل القصيرة بتغيير `CHANNEL` إلى `sms` — عبر فودافون قطر (خدمة SMS Connect للشركات، وتحتاج اسم مرسل مسجَّلًا لدى هيئة تنظيم الاتصالات) أو Twilio. لكن البريد أسرع وبلا تكلفة.
